# Cat Petting Simulator

3D ragdoll-physics cat petting. Drive a physically simulated arm with your
mouse. Pet the cat. The cat has opinions.

Built with Three.js, Rapier (WASM), Vite, and TypeScript.

## Development

```bash
npm install
npm run dev
npm test       # headless physics + ragdoll stability checks
```

See [PLAN.md](PLAN.md) for the roadmap.
